# AGENTS.md

## Project

TaskVerde is a simple to-do list app built with React, Vite, and Tailwind CSS.

## User Request

Create a simple to-do list app from scratch. Users should be able to:

- Create a to-do.
- View created to-dos.
- Edit a to-do when needed.
- Delete a to-do.

Keep the app simple and meaningful. Follow the green TaskVerde theme from the provided UI reference, but remove complex dashboard elements such as ratings, analytics, project counts, storage widgets, advanced filters, and dense sidebar metrics.

## Implementation Notes

- Use React components with clear state management.
- Use Tailwind utility classes for styling.
- Prefer a calm, clean green theme inspired by TaskVerde.
- Keep the first screen focused on the usable to-do experience.
- Avoid adding authentication, project management, team features, analytics, or backend services unless explicitly requested.
- Store tasks locally in the browser unless a later instruction asks for a backend.
